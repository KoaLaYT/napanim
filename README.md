# napanim

using zig and [raylib](https://www.raylib.com/) to try out any kind of interesting animation.

mainly a copy of [panime](https://github.com/tsoding/panim).

### How to run

```bash
$ make run          # start the base

$ make build/plugin # hot reload
```
